# Design and Simulation of a Two-Stage CMOS Operational Amplifier using LTspice

## Overview

This project presents the design and simulation of a transistor-level two-stage CMOS operational amplifier using LTspice. The amplifier consists of a CMOS differential input stage with PMOS current mirror active loads, followed by a common-source gain stage and Miller compensation capacitor for stability improvement.

## Features

* CMOS Differential Amplifier
* PMOS Current Mirror Active Load
* Common Source Second Gain Stage
* Current Source Biasing
* Miller Compensation
* DC Operating Point Analysis
* AC Frequency Response Analysis
* Transient Response Analysis

## Software Used

* LTspice XVII

## Circuit Architecture

Differential Pair → Current Mirror Load → Gain Stage → Compensation Capacitor → Output

## Simulations Performed

1. DC Operating Point Analysis
2. AC Frequency Response Analysis
3. Transient Response Analysis

## Learning Outcomes

* Differential amplification
* Current steering in MOSFETs
* Current mirror operation
* Frequency compensation
* Gain-bandwidth tradeoffs
* Analog IC design fundamentals
